# Sales Performance Dashboard

## 📊 Project Overview

An interactive Power BI dashboard designed to analyze sales performance, profitability, orders, quantity, regional performance, category performance, and payment methods.

## 🛠️ Tools Used

- Power BI
- Microsoft Excel
- DAX
- Data Visualization

## 📌 Dashboard KPIs

- Total Sales
- Total Profit
- Profit Margin %
- Average Order Value
- Total Orders
- Total Quantity

## 📈 Dashboard Features

- Monthly Sales Trend
- Sales by Category
- Sales by Region
- Profit by Category
- Profit by State
- Sales by Payment Mode
- Interactive Year filter
- Interactive Category filter
- Interactive Region filter

## 🎛️ Interactive Filters

The dashboard allows users to filter the analysis by:

- Year
- Category
- Region

All charts and KPI cards update dynamically based on the selected filters.
